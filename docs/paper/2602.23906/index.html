# 論文摘要翻譯 當文字描述附加了額外的細節時，如果該細節是錯誤的，圖像文字相似度應該會下降。我們展示 CLIP 風格的雙編碼器經常違反這個直觀認知：在原本正確的描述中附加一個看似合理但實際錯誤的物體或關係，反而可能提高相似度分數。我們稱這類情況為半真實（half-truths）。在 COCO 上，CLIP 只在 40.6% 的時間內偏好正確的較短描述，當附加的細節是關係時，性能下降到 32.9%。我們將此脆弱性追溯到標題部分的弱監督：對比學習對齊完整句子，但沒有明確強制個別實體和關係被正確接地。我們提出 CS-CLIP（Component-Supervised CLIP），它將標題分解為實體和關係單位，為每個單位構造最小編輯的對比樣本，並微調模型使其對正確單位的評分高於對應的對比樣本，同時保持標準雙編碼器推理。CS-CLIP 將半真實準確度提升到 69.3%，並在已確立的組成性基準上平均性能提升 5.7 個百分點，表明減少半真實錯誤與更廣泛的組成性理解進展相一致。程式碼公開於：https://github.com/kargibora/CS-CLIP

When a text description is extended with an additional detail, image-text similarity should drop if that detail is wrong. We show that CLIP-style dual encoders often violate this intuition: appending a plausible but incorrect object or relation to an otherwise correct description can increase the similarity score. We call such cases half-truths. On COCO, CLIP prefers the correct shorter description only 40.6% of the time, and performance drops to 32.9% when the added detail is a relation. We trace this vulnerability to weak supervision on caption parts: contrastive training aligns full sentences but does not explicitly enforce that individual entities and relations are grounded. We propose CS-CLIP (Component-Supervised CLIP), which decomposes captions into entity and relation units, constructs a minimally edited foil for each unit, and fine-tunes the model to score the correct unit above its foil while preserving standard dual-encoder inference. CS-CLIP raises half-truth accuracy to 69.3% and improves average performance on established compositional benchmarks by 5.7 points, suggesting that reducing half-truth errors aligns with broader gains in compositional understanding. Code is publicly available at: https://github.com/kargibora/CS-CLIP

半真會破壞相似度的檢索

當文本描述被添加額外的細節時，如果該細節是錯誤的，圖像-文本相似度應該會下降。 我們展示 CLIP 風格的雙編碼器經常違反這種直覺：在原本正確的描述後附加一個看似合理但不正確的物體或關係，可能會增加相似度分數。 我們將這類情況稱為半真。 在 COCO 上，CLIP 僅在 40.6% 的時間內偏好正確的較短描述，當添加的細節是關係時，性能下降到 32.9%。 我們將此漏洞追溯到對標題部分的弱監督：對比訓練對齊完整句子，但不明確地強制個別實體和關係被基礎化。 我們提出 CS-CLIP（Component-Supervised CLIP），它將標題分解為實體和關係單位，為每個單位構建最小編輯的對比樣本，並微調模型使其對正確單位的評分高於其對比樣本，同時保留標準的雙編碼器推論。 CS-CLIP 將半真準確率提高到 69.3%，並在已建立的組合基準上平均性能提高 5.7 個百分點，表明減少半真錯誤與組合理解方面更廣泛的進步相一致。程式碼公開於：https://github.com/kargibora/CS-CLIP/ 。

1 介紹

描述影像時，加入錯誤的細節應該會降低描述的相關性，而非提高。 如果「一隻狗」正確地描述了一張影像，那麼當狗並不在滑板上時，「一隻狗在滑板上」應該得到更低的相似度分數。 我們展示 CLIP 風格的雙編碼器（Radford et al., 2021）違反了這一原則：追加單一個不正確但看似合理的細節往往會增加相似度。

圖 1：半真實漏洞。從一個簡短的、有圖說支持的描述（錨點）開始，我們透過新增一個現實但不正確的細節形成半真實描述：要麼是錯誤的實體描述，要麼是實體之間的錯誤關係。 CLIP（Radford et al., 2021）和 NegCLIP（Yuksekgonul et al., 2023）對半真實描述指派了更高的相似度，而 CS-CLIP（我們的方法）正確地對不正確的新增部分進行了懲罰。

我們將這一失敗形式化為半真實漏洞。 給定一張影像，我們從一個簡短的、有圖說支持的錨點描述開始。 然後我們透過追加恰好一個在上下文中流暢且看似合理但對該影像不正確的額外單位來形成半真實描述。 被追加的單位要麼是實體單位（錯誤的實體描述），要麼是關係單位（涉及錨點實體的錯誤關係）。 圖 1 展示了兩種情況：不正確的實體新增（log $\rightarrow$ log 和 zebras）和不正確的關係新增（elephants away from the log 而非 near），其中 CLIP（Radford et al., 2021）和 NegCLIP（Yuksekgonul et al., 2023）對半真實描述的評分高於錨點，而 CS-CLIP 正確地傾向於錨點。

這個漏洞很常見。 在 MS-COCO（Lin et al., 2014）上，CLIP 在總體情況下只有 $40.6\%$ 的時間內將錨點排在半真實描述之上，在不正確新增為關係時僅有 $33.2\%$。 SigLIP（Zhai et al., 2023）達到總體 $45.7\%$，SigLIP2（Tschannen et al., 2025）達到 $54.6\%$，兩者都接近或低於隨機機率。 即使使用句子級困難負樣本進行訓練也只能適度改進： NegCLIP 在總體上達到 $56.5\%$，但在關係新增時仍低於機率水平（$48.3\%$）。 單一個錯誤的細節，尤其是關係型的，並未被可靠地懲罰。

這種模式類似於合取謬誤，其中新增一個看似合理的細節會增加感知的可能性，儘管合取在邏輯上更具限制性（Tversky & Kahneman, 1983）； 這裡新增的細節是看似合理但錯誤的，然而相似度仍然上升。與先前關於組合理解的工作的關鍵區別是操作本身： 現有的基準測試模型是否能區分互換或重新排列資訊的圖說（例如「紅貓和藍狗」vs.「藍貓和紅狗」）（Yuksekgonul et al., 2023；Thrush et al., 2022）， 而半真實測試則考驗模型是否對不正確的新增進行懲罰。

為什麼會發生這種情況？

對比訓練將影像與完整圖說對齐。 這在句子級別提供了強有力的監督，但對於組成圖說含義的各個單位則是較弱的監督。 因此，相似度可能由粗粒度的重疊支配（例如，偵測到正確的物體），而額外的看似合理的單位可能會增加相似度，即使它是不正確的，尤其是對於需要驗證實體如何組合的關係和角色敏感的結構。

我們的方法：單位級監督。

我們提出 CS-CLIP（Component-Supervised CLIP），在微調期間對圖說單位添加顯式監督。 我們將每個圖說解析為實體單位（帶有綁定屬性的名詞短語）和關係單位（實體之間的有向關係）。 對於每個單位，我們生成一個最小編輯的對比項，在保持流暢性和上下文的同時改變含義（例如，「brown horse」$\to$ 「white horse」，或 「horse near barn」$\to$ 「horse inside barn」）。 在訓練期間，我們將每個正確的單位與其對比項進行對比，教導模型對細粒度的組合差異進行回應。 至關重要的是，這個監督僅在訓練期間應用，在測試時， CS-CLIP 使用與標準 CLIP 相同的雙編碼器架構和相同的檢索評分方式。

CS-CLIP 在 COCO 上達到 $69.3\%$ 的半真實準確度，相比之下 CLIP 為 $40.6\%$，NegCLIP 為 $56.5\%$。 它還在 16 個已確立的組合基準上進行了改進，在評估的模型中達到了最佳的平均影像到文本準確度（$57.8\%$）和組準確度。

  • 方法。CS-CLIP 透過單位級監督對 CLIP 進行微調：每個實體和關係單位都與一個相應的對比項進行對比。 這實現了 $69.3\%$ 的半真實準確度（相比 CLIP 的 $40.6\%$），同時保留了標準雙編碼器推論。

2 相關工作

對比式視覺語言預訓練與組合敏感性。對比式雙編碼器（如 CLIP 和 ALIGN）學習影像和文本的共享嵌入空間，透過單一相似度分數實現有效檢索（Radford et al., 2021；Jia et al., 2021）。一個反覆出現的關切是，此分數可能會低估語言結構的使用：CLIP 風格的模型在包含屬性綁定、詞序和關係等改變意義的最小編輯下，表現得像詞袋模型（Yuksekgonul et al., 2023；Thrush et al., 2022）。最近的分析表明，這在很大程度上是跨模態的問題：綁定線索可能存在於單一模態內，但在餘弦相似度對齐中並未被可靠地反映（Koishigarina et al., 2025）；其他工作報告了偏好中心物體或頻繁屬性物體配對的評分偏差（Schrodi et al., 2025；Tang et al., 2023）。為了評估這一點，控制編輯基準（controlled-edit benchmarks）測試模型是否能區分正確的影像文本配對和最小編輯替代方案，包括 ARO、Winoground、SugarCrepe 和 VALSE（Yuksekgonul et al., 2023；Thrush et al., 2022；Hsieh et al., 2023；Parcalabescu et al., 2022），以及針對特定現象的目標測試（Burapacheep et al., 2024；Kamath et al., 2023；Paiss et al., 2023）。

新增資訊與我們的診斷方法。除了交換和重新排序，多項工作研究了當更多資訊被添加到輸入時模型信心如何變化。HiMo-CLIP 以正確新增為條件來目標單調對齐（Wu et al., 2025），而大語言模型推理中的信心膨脹模式顯示，添加的可信內容可在具誤導性的輸入下膨脹信心（Suri et al., 2023；Richardson et al., 2025；Jiang et al., 2024a）。我們的工作是補充性的：我們透過半真半假診斷（half-truth diagnostic）測試相似度是否能恰當地懲罰不正確的新增，該診斷會在正確描述中附加一項真實但不正確的細節（第 3 節）。

組合敏感性的訓練方法。許多方法通過資料層級的信號來強化敏感性：編輯物體、屬性或關係的句級難負例（Yuksekgonul et al., 2023；Zhang et al., 2024；Peleg et al., 2025；Singh et al., 2025；Patel et al., 2024）、場景圖擾動（Singh et al., 2023）或標題合成（Fan et al., 2023；Doveh et al., 2023a；Castro et al., 2024；Doveh et al., 2023b；Nayak et al., 2023）。其他方法添加架構元件或輔助目標，例如區域對齐（Zhong et al., 2022；Huang et al., 2024）、輔助模組（Yao et al., 2021；Goel et al., 2022；Abdollah et al., 2024；Oh et al., 2024；Kwon et al., 2025）或多階段訓練（Hu et al., 2025），而有些則透過分解來修改推理（Jiang et al., 2024b；Miranda et al., 2025；Menon & Vondrick, 2022）。我們建立在句級負例之上，但添加了有針對性的單位級監督：對於每個標題，我們解析實體和關係單位，並將每個單位與最小編輯的對照項進行對比。這在保持標準雙編碼器架構的同時，對各別標題部分施加了直接的組合壓力（第 4 節）。

3 半真實漏洞

3.1 動機

先前關於 CLIP 風格模型中組合敏感性的研究主要關注最小編輯，這些編輯交換或重新排列現有資訊（例如，「紅色貓和藍色狗」與「藍色貓和紅色狗」）(Yuksekgonul et al., 2023 ; Thrush et al., 2022)。我們研究一個互補的失敗模式：添加不正確的資訊。直觀地，添加合理但不正確的細節應該會降低相似度，因為描述變得不夠準確。然而，如果相似度依賴於匹配個別詞彙或概念，而不驗證組合的正確性，添加的細節可能不會受到懲罰，甚至可能增加相似度。

3.2 半真理診斷：指標與構造

錨點 vs. 半真理。

給定一張影像 I I ，我們比較一個簡短描述，即錨點 A A ，與一個半真理 A − A^{-} ，後者是通過附加恰好一個額外細節形成的。 錨點是一個單一實體單位：描述影像中存在的物體的名詞短語，可能帶有屬性或數量。 添加的細節在上下文中是合理的，但對於該影像是不正確的。 我們將半真理準確度報告為模型偏好錨點而非半真理的案例比例：

Sentence-level fine-tuning improves both categories but leaves a substantial gap. NegCLIP (Yuksekgonul et al., 2023 ) raises entity accuracy to 69.8 % 69.8\% and relation accuracy to 48.3 % 48.3\% , bringing relation additions closer to random chance. Why unit-level supervision?

Since half-truths differ from anchors by exactly one unit, we hypothesize that explicit unit-level supervision, contrasting each correct unit against a minimally edited foil, will make similarity more sensitive to the specific detail that changed.

4 方法：CS-CLIP

半真診斷揭示了當錯誤訊息被添加到正確描述中時，模型會遇到困難。 為了解決這個問題，我們在微調期間引入了單位級別的監督。 與其直接在錨點對比半真的訓練上進行，我們在單位級別提供監督：對於每個標題單位，我們將正確的單位與最小編輯的負例進行對比（例如，「褐色馬」對比「白色馬」）。 這針對性地解決了潛在的弱點，即對組合結構的敏感性，使該方法在半真設定之外具有通用性。

標準 CLIP 訓練使用全局對比目標將每個影像與其完整標題對齐，這可能使相似度分數對個別標題部分不夠敏感（第 3 節）。 為了解決這個問題，我們提出了 CS-CLIP（Component-Supervised CLIP），它在微調期間添加了有針對性的單位級別監督，同時在測試時保持雙編碼器架構和標準餘弦相似度評分不變。

對於每個影像標題對，我們將標題解析為實體單位和關係單位（在第 3 節中定義），取樣一個單位及其匹配的負例，並訓練影像嵌入使其對正確單位的評分高於負例。 這種對標題部分的直接監督使相似度對個別細節更加敏感，同時通過並行的句子級別損失保持全標題對齐。 圖 4 說明了完整的訓練流程。

圖 4：CS-CLIP 訓練流程。(i) 單位提取與負例生成。給定標題 $T_j$，僅文本的 LLM 提取實體單位和關係單位，然後通過最小的、逼真的編輯為每個單位生成匹配的負例（例如，「褐色馬」→「白色馬」）。(ii) 單位取樣與編碼。我們為每個影像取樣一個單位負例對 $(U_j, \tilde{U}j)，用 $f\phi$ 編碼影像 $I_j$ 和用 $g_\phi$ 編碼單位文本。(iii) 單位級別監督。單位損失 $\mathcal{L}_{\mathrm{unit}}$ 將影像嵌入 $i_j$ 拉向正確的單位 $u_j$ 並推開匹配的負例 $\tilde{u}_j$ 和其他批內單位。句子級別對比訓練並行應用（未顯示）。

4.1 單位採樣和編碼

我們重複使用第 3 節的純文字解析管道，從每個標題 $T$ 中提取實體單位 $\mathcal{E}(T)$ 和關係單位 $\mathcal{R}(T)$，以及每個單位的匹配對照樣本（附錄 B 提供實作細節）。

採樣策略。針對每個影像-標題配對，我們從實體或關係中採樣一個單位 $U$。 以機率 $p_{\mathrm{rel}}$ 採樣一個關係單位 $U\in\mathcal{R}(T)$； 否則，我們採樣一個實體單位 $U\in\mathcal{E}(T)$，可選地形成最多 $K{=}2$ 個實體的連接。 我們採樣該單位的匹配對照樣本 $\tilde{U}$，並使用文字編碼器 $g_{\phi}(\cdot)$ 將兩者編碼為名詞短語（實體）或述詞短語（關係），產生正規化嵌入。 我們在附錄 F 中調查其他採樣策略。

4.2 訓練目標

句子級損失（ℒ global \mathcal{L}_{\mathrm{global}} ）。我們使用標準的全局圖像-標題對比目標，結合 NegCLIP 風格的困難負樣本（Yuksekgonul et al., 2023）（附錄 A），將其與單位級監督相結合，以提高對組合結構的敏感性。

單位級損失（ℒ unit \mathcal{L}_{\mathrm{unit}} ）。對於單位監督，我們使用與 CLIP 相同的余弦評分，具有可學習的溫度參數 τ \tau。由於嵌入已歸一化，余弦相似度等於點積。我們定義

κ ​ ( 𝐱 , 𝐲 ) = exp ⁡ ( 𝐱 ⊤ ​ 𝐲 τ ) . \kappa(\mathbf{x},\mathbf{y})=\exp!\left(\frac{\mathbf{x}^{\top}\mathbf{y}}{\tau}\right). (2)

對於每個圖像 I i I_{i}，我們採樣 N u N_{u} 個單位/假樣本對 { ( U i , k , U ~ i , k ) } k = 1 N u {(U_{i,k},\tilde{U}{i,k})}{k=1}^{N_{u}}。設 𝐯 i \mathbf{v}{i} 表示歸一化的圖像嵌入，設 𝐮 i , k \mathbf{u}{i,k} 和 𝐮 ~ i , k \tilde{\mathbf{u}}_{i,k} 表示第 k k 個單位及其對應假樣本的歸一化嵌入，對應於圖像 i i。

對於固定的單位索引 k k，圖像到單位的損失為：

ℒ I → U ( k ) = − 1 B ​ ∑ i = 1 B log ⁡ κ ​ ( 𝐯 i , 𝐮 i , k ) ∑ j = 1 B κ ​ ( 𝐯 i , 𝐮 j , k ) + κ ​ ( 𝐯 i , 𝐮 ~ i , k ) . \mathcal{L}^{(k)}{I\rightarrow U}=-\frac{1}{B}\sum{i=1}^{B}\log\frac{\kappa(\mathbf{v}{i},\mathbf{u}{i,k})}{\sum_{j=1}^{B}\kappa(\mathbf{v}{i},\mathbf{u}{j,k})+\kappa(\mathbf{v}{i},\tilde{\mathbf{u}}{i,k})}. (3)

此損失訓練圖像給正確的單位 U i , k U_{i,k} 打出更高的分數，相比於（i）其對應的假樣本 U ~ i , k \tilde{U}_{i,k} 和（ii）來自其他圖像的批次內單位。

我們也包括對稱的單位到圖像項：

ℒ U → I ( k ) = − 1 B ​ ∑ i = 1 B log ⁡ κ ​ ( 𝐯 i , 𝐮 i , k ) ∑ j = 1 B κ ​ ( 𝐯 j , 𝐮 i , k ) . \mathcal{L}^{(k)}{U\rightarrow I}=-\frac{1}{B}\sum{i=1}^{B}\log\frac{\kappa(\mathbf{v}{i},\mathbf{u}{i,k})}{\sum_{j=1}^{B}\kappa(\mathbf{v}{j},\mathbf{u}{i,k})}. (4)

我們在公式 4 中排除假樣本，因為每個假樣本都與特定的圖像-單位對相綁定；公式 4 提供雙向正則化。

我們對採樣的 N u N_{u} 個單位索引進行平均：

ℒ unit = 1 2 ​ N u ​ ∑ k = 1 N u ( ℒ I → U ( k ) + ℒ U → I ( k ) ) . \mathcal{L}{\mathrm{unit}}=\frac{1}{2N{u}}\sum_{k=1}^{N_{u}}\Big(\mathcal{L}^{(k)}{I\rightarrow U}+\mathcal{L}^{(k)}{U\rightarrow I}\Big). (5)

最終目標。我們將全局對齊與單位級監督相結合：

ℒ CS = ℒ global + λ u ​ ℒ unit . \mathcal{L}{\mathrm{CS}}=\mathcal{L}{\mathrm{global}}+\lambda_{u}\,\mathcal{L}_{\mathrm{unit}}. (6)

此目標保持標準 CLIP 推理不變，但通過訓練模型區分正確的標題單位與其對應的假樣本，使學習的相似度對標題結構更敏感。通過提供單位級監督而非直接在錨點對半真值比較上進行訓練，此方法針對一般組合弱點，並改善了超越半真值診斷的性能（第 5.2 節）。

5.2 組合式理解

半真相診斷隔離了對單一不正確添加細節的敏感性。 我們現在評估 CS-CLIP 的單元級監督是否在已建立的基準上更廣泛地改進了組合式理解，這些基準測試屬性綁定、關係和其他受控的語言變異。

我們在一套基於受控對比的組合式基準上評估 CS-CLIP，包括 ARO（Yuksekgonul et al., 2023）、SugarCrepe（Hsieh et al., 2023）、Winoground（Thrush et al., 2022）和其他廣泛使用的基準。 在這些基準中，模型必須對正確的圖像-文本對分配比最小編輯的替代方案更高的相似度。 我們報告圖像到文本（I2T）和文本到圖像（T2I）的準確度。對於配對資料集（如 Winoground），我們也報告群組準確度（Grp）， 這要求 I2T 和 T2I 都正確。 完整的基準詳情和協議在附錄 E.1 中提供。

整體組合式性能。圖 5 繪製了不同模型的平均組合式 I2T 準確度與半真相準確度的對比。 CS-CLIP 在兩個指標上都達到最佳性能：57.8% 組合式 I2T（表 11）和 69.3% $\mathrm{Acc}_{\mathrm{HT}}$ 在 COCO 上。 模型間的正相關驗證了單元級監督解決的是一般組合式弱點，而不是對半真相設置的過度擬合。

資料集分解。CS-CLIP 在 14/16 個基準上改進了 NegCLIP（圖 6） 並超越了最近的基準方法（FSC-CLIP 57.4%、ReadCLIP 56.9%、DeGLA 56.2%）。 與這些添加架構組件或多階段訓練的方法不同， CS-CLIP 僅通過額外的單元級監督實現收益，無需修改 雙編碼器架構或測試時評分。 CS-CLIP 達到了最佳 VL Checklist（Zhao et al., 2022）得分（79.2%）， 該得分是對物體、屬性和關係的系統審計。

6 結論

我們研究了 CLIP 風格模型中的一個簡單檢索失敗現象：將一個現實但不正確的細節附加到正確的描述中可能會增加相似度，使得半真實性描述的排名超過錨點。

為了解決這個問題，我們引入了 CS-CLIP，它在微調期間通過將標題解析為實體和關係單位，並將每個單位與最小編輯的反例進行對比，從而添加單位級監督。

這在保持標準雙編碼器架構的同時，提供了直接的組合壓力。

CS-CLIP 達成了 69.3% 的半真實性準確度（相比 CLIP 的 40.6%）、最佳的組合圖文檢索準確度（57.8%），以及在評估方法中最高的群組準確度，證明了針對標題部分的有針對性監督使檢索對組合變化更敏感。

局限性和未來工作。我們的方法依賴於純文本 LLM 解析，這可能會引入偽影或遺漏標題中未表達的視覺細節，且在 COCO 上微調會在零樣本準確度和組合敏感性之間進行權衡。

雖然 CS-CLIP 減少了半真實性失敗，但它不能保證事實正確性或人口統計公平性；模型可能仍然反映訓練資料中存在的偏見。

未來的工作可以探索圖像端的半真實性（向正確的圖像添加不正確的視覺元素）、利用視覺基礎的聯合圖像文本解析，或在大規模預訓練期間應用單位級監督以減少零樣本權衡。

本工作解決了視覺語言檢索中的一個失敗模式，其中向查詢添加不正確的細節可能會逆向性地增加相似度分數。

附錄 A 句子級全局目標函數

本附錄定義了來自方程式 6（第 4.2 節）的句子級對比目標函數 $\mathcal{L}_{\mathrm{global}}$，並總結了 NegCLIP（Yuksekgonul et al., 2023）如何透過合成困難負例標題來修改分母。

我們使用來自方程式 2 的評分記號，其中所有嵌入都經過 $\ell_{2}$ 歸一化，使得餘弦相似度等於點積。

A.1 CLIP 全局對比損失函數

考慮一個大小為 $B$ 的小批次，包含 $B$ 個配對的圖像–標題對 ${(I_{i},T_{i})}{i=1}^{B}$。 令 $\mathbf{v}{i}$ 為歸一化的圖像嵌入，$\mathbf{t}_{i}$ 為歸一化的標題嵌入。 圖像到文本（I2T）損失函數為

$\mathcal{L}{I\rightarrow T}=-\frac{1}{B}\sum{i=1}^{B}\log\frac{\kappa(\mathbf{v}{i},\mathbf{t}{i})}{\sum_{j=1}^{B}\kappa(\mathbf{v}{i},\mathbf{t}{j})}$ (7)

對稱的文本到圖像（T2I）損失函數為

$\mathcal{L}{T\rightarrow I}=-\frac{1}{B}\sum{i=1}^{B}\log\frac{\kappa(\mathbf{v}{i},\mathbf{t}{i})}{\sum_{j=1}^{B}\kappa(\mathbf{v}{j},\mathbf{t}{i})}$ (8)

我們將全局 CLIP 目標函數定義為

$\mathcal{L}{\mathrm{CLIP}}=\frac{1}{2}\Big(\mathcal{L}{I\rightarrow T}+\mathcal{L}_{T\rightarrow I}\Big)$ (9)

A.2 NegCLIP-style hard negative captions

NegCLIP (Yuksekgonul et al., 2023 ) augments each training example with a shuffled-caption hard negative. Given a caption T i T_{i} , it constructs a foil T ~ i \tilde{T}{i} by shuffling or swapping content words (e.g., nouns, adjectives) so that the new sentence reuses nearly the same vocabulary but changes the sentence-level meaning. Let 𝐭 ~ i \tilde{\mathbf{t}}{i} denote the normalized embedding of the shuffled caption T ~ i \tilde{T}_{i} .

NegCLIP then adds these shuffled negatives to the image-to-text denominator. With a minibatch of B B pairs, the I2T loss becomes

ℒ I → T Neg = − 1 B ​ ∑ i = 1 B log ⁡ κ ​ ( 𝐯 i , 𝐭 i ) ∑ j = 1 B κ ​ ( 𝐯 i , 𝐭 j ) + ∑ j = 1 B κ ​ ( 𝐯 i , 𝐭 ~ j ) . \mathcal{L}{I\rightarrow T}^{\mathrm{Neg}}=-\frac{1}{B}\sum{i=1}^{B}\log\frac{\kappa(\mathbf{v}{i},\mathbf{t}{i})}{\sum_{j=1}^{B}\kappa(\mathbf{v}{i},\mathbf{t}{j})\;+\;\sum_{j=1}^{B}\kappa(\mathbf{v}{i},\tilde{\mathbf{t}}{j})}. (10)

That is, each image 𝐯 i \mathbf{v}{i} is contrasted against all B B in-batch captions { 𝐭 j } {\mathbf{t}{j}} plus all B B shuffled-caption foils { 𝐭 ~ j } {\tilde{\mathbf{t}}_{j}} from the same batch.

The text-to-image term remains unchanged from Eq. 8 (i.e., no hard negatives are added in the T2I direction). We define the NegCLIP objective as

ℒ NegCLIP = 1 2 ​ ( ℒ I → T Neg + ℒ T → I ) . \mathcal{L}{\mathrm{NegCLIP}}=\frac{1}{2}\Big(\mathcal{L}{I\rightarrow T}^{\mathrm{Neg}}+\mathcal{L}_{T\rightarrow I}\Big). (11)

Relation to CS-CLIP.

Unless otherwise stated, CS-CLIP uses the NegCLIP-style objective (Eq. 11 ) as ℒ global \mathcal{L}{\mathrm{global}} . In our ablation studies (Appendix F ), we also explore using the standard CLIP objective (Eq. 9 ) without hard negatives. We then add λ u ​ ℒ unit \lambda{u}\,\mathcal{L}_{\mathrm{unit}} (Eq. 6 ) to provide supervision on individual caption units and their matched foils.

E.1 評估協議和指標

組合基準測試呈現對比集合，其中一項是正確的，一項或多項干擾項因最小語義變化而不同（例如，交換角色、改變屬性或改變詞序）。 令 $s(I,T)$ 表示模型的圖像－文本相似度分數。

圖像到文本 (I2T) 準確度。

對於每個圖像 $I_i$，基準測試提供候選標題集合 $\mathcal{T}{i}={T{i,1},\ldots,T_{i,m_{i}}}，其中包含單一正確標題 $T_{i}^{\star}\in\mathcal{T}_{i}$。 I2T 準確度是正確標題排名高於所有干擾項的案例比例：

$\mathrm{Acc}{\mathrm{I2T}}=\frac{1}{N}\sum{i=1}^{N}\mathbb{I}\Big[s(I_{i},T_{i}^{\star})\;>\;\max_{T\in\mathcal{T}{i}\setminus{T{i}^{\star}}}s(I_{i},T)\Big].$ (12)

當 $\mathcal{T}_{i}$ 恰好包含一個干擾項時，這簡化為成對勝率。

文本到圖像 (T2I) 準確度。

對於每個文本查詢 $T_i$，基準測試提供候選圖像集合 $\mathcal{I}{i}={I{i,1},\ldots,I_{i,n_{i}}}，其中包含單一正確圖像 $I_{i}^{\star}\in\mathcal{I}_{i}$。 T2I 準確度是正確圖像排名高於所有干擾項的案例比例：

$\mathrm{Acc}{\mathrm{T2I}}=\frac{1}{N}\sum{i=1}^{N}\mathbb{I}\Big[s(I_{i}^{\star},T_{i})\;>\;\max_{I\in\mathcal{I}{i}\setminus{I{i}^{\star}}}s(I,T_{i})\Big].$ (13)

群組準確度。

某些基準測試提供包含 $n$ 對匹配圖像－標題對的群組 ${(I_{i,1},T_{i,1}),\ldots,(I_{i,n},T_{i,n})}$。 群組準確度是模型在雙向上為匹配對分配最高相似度相比所有不匹配對的群組比例：

$\mathrm{Acc}{\mathrm{Grp}}=\frac{1}{N{g}}\sum_{i=1}^{N_{g}}\mathbb{I}\Big[\forall j\in{1,\ldots,n}:\;s(I_{i,j},T_{i,j})>\max\Big(\max_{k\neq j}s(I_{i,k},T_{i,j}),\max_{\ell\neq j}s(I_{i,j},T_{i,\ell})\Big)\Big].$ (14)

平均化。

我們報告每個基準測試的準確度和套件級平均值，計算方式為基準測試級準確度的未加權平均。 針對能力方面的分析，我們計算每個基準測試子集的準確度，然後在各能力類別內進行巨觀平均（附錄 D.2）。
